# miru

Eagle風のローカル画像レビューツール。Node.js (Express + better-sqlite3 + sharp) のローカルサーバー + ブラウザUIで、非破壊的に画像フォルダをインデックスして管理します。

## 概要

- ローカルフォルダの画像を非破壊的にインデックス
- 画像は元の場所のまま、メタデータだけ `data/miru.db` に保存
- レーティング、リジェクト、タグ、検索に対応

## セットアップ

```bash
npm install
node server.js /path/to/images [/path/to/more/images ...]
```

ブラウザで http://localhost:3777 を開きます。

**環境変数:**
- `PORT` - サーバーポート（デフォルト 3777）
- `MIRU_DATA` - データベース保存先（デフォルト `./data`）

## サンプル画像で試す

```bash
npm run samples
node server.js samples
```

## 機能

- **サムネイルグリッド** - 画像を一覧表示
- **レーティング (1-5)** - 5段階で評価
- **リジェクト (X)** - 不要な画像をマーク
- **タグ** - カスタムタグで分類
- **検索** - ファイル名・タグで検索
- **並び替え** - 新しい順・古い順・レート順・名前順・シャッフル
- **フォルダ管理** - 複数フォルダの一元管理
- **ライトボックス** - 拡大表示

## キーボードショートカット

| キー | 動作 |
|------|------|
| ← → ↑ ↓ | 選択移動 |
| 1-5 | レーティング |
| 0 | レーティング解除 |
| X | リジェクト |
| T | タグ入力 |
| Enter | 拡大表示 |
| Esc | ライトボックス閉じる |
| / | 検索フォーカス |

## AI自動タグ付け

環境変数 `MIRU_TAGGER` で AI エンジンを選択:

- `ollama` - ローカル Ollama (デフォルト: qwen2.5vl)
- `claude` - Claude Code CLI 経由（サブスクリプション内、デフォルト: haiku）
- `codex` - Codex CLI 経由（ChatGPT サブスクリプション内）

**使い方:**
- ライトボックスの「✨ AIタグ」ボタンをクリック
- または `POST /api/autotag` で未タグ画像を一括処理

**環境変数:** `MIRU_TAGGER_MODEL` でモデルを指定。API課金なしで動きます。
